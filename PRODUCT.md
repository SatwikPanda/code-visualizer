# Code Visualizer

An operating workspace for learners inspecting small Java and C++20 algorithms. Paste code, detect function or method parameters, provide values, and follow recorded runtime observations through to the result. Source, detected inputs, and a wide step table remain the primary surfaces. A synchronized animated data canvas explains arrays, containers, iterator positions, scalar changes, and function calls. Preserve submitted code and its actual errors. Playback navigates a recording; motion illustrates changes between snapshots. Languages share the value and trace contract, with separate execution histories.
